# Papéis de Parede do Medro

Esta pasta contém os papéis de parede do sistema para o **Modo Claro** e o **Modo Escuro**.

## Estrutura de Nomes

Para substituir pelos seus próprios papéis de parede em imagem (`.jpg` ou `.png`), basta colocar os arquivos nesta pasta com os nomes correspondentes:

### Opção 1
* `wallpaper-1-light.jpg` (ou `.png` / `.svg`) — Modo Claro
* `wallpaper-1-dark.jpg` (ou `.png` / `.svg`) — Modo Escuro

### Opção 2
* `wallpaper-2-light.jpg` (ou `.png` / `.svg`) — Modo Claro
* `wallpaper-2-dark.jpg` (ou `.png` / `.svg`) — Modo Escuro

> 💡 **Dica de Resolução:** Recomendamos imagens com proporção 16:9 ou formato desktop (ex: 1920×1080 ou 2560×1440).
> O app já inclui fallbacks vetoriais SVG de alta qualidade com a paleta oficial se as fotos ainda não tiverem sido adicionadas.
